## 📌 프로젝트 소개

**Berkeley Humanoid Lite (BHL)** 프로젝트의 진행 사항, 문서, 실험 기록, 코드 자산을 관리하고 공유하기 위한 저장소입니다.

## 🎯 주요 목표

- 휴머노이드 플랫폼 개발 및 고도화
- 조작(Manipulation) 및 이동(Mobility) 성능 개선
- 실제 환경에서 동작 가능한 지능형 로봇 기능 구현
- 시뮬레이션-실환경 연계 워크플로우 구축

## 🧩 포함 내용

- 프로젝트 문서 및 개발 노트
- 실험/테스트 기록
- 코드 및 설정 파일
- 이슈 및 작업 진행 내역

## 🚀 시작하기

> 아래 항목은 저장소 구조에 맞게 수정해서 사용하세요.

1. 저장소 클론
   ```bash
   git clone https://github.com/SCPS-LAB-koreatechU/Berkeley-humanoid-lite.git
   cd Berkeley-humanoid-lite
   ```

2. 개발 환경 준비  
   - Python, C++, ROS 2 등 프로젝트 의존성 설치

3. 실행/테스트  
   - 프로젝트 실행 방법 및 테스트 절차를 여기에 추가
