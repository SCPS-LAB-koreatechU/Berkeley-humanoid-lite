# 결합부 어댑터 출력·조립 가이드

부품: `bhl_v1_forearm_adapter` (elbow_roll 플랜지 ↔ DexHand V1 전완 커프)
파일: `meshes_adapter/bhl_v1_forearm_adapter.stl`(mm, 출력용) ·
`cad/bhl_v1_forearm_adapter.step`(CAD 수정용) ·
`cad/bhl_v1_forearm_adapter_drawing.pdf`(치수 도면)

## 출력 설정 (Bambu Studio 기준)

| 항목 | 권장값 | 비고 |
|---|---|---|
| 배치 | 모델 그대로 (Ø44 베이스면이 베드) | 지지대 불필요 |
| 재료 | PLA(기본) / PETG(내열 여유) | 관성값은 솔리드 PLA 기준 50.8g |
| 벽 수 | 4 이상 | 칼라 벽두께 5mm → 사실상 솔리드 |
| 인필 | 30–40% Gyroid | 플레이트·플로어 강성 확보 |
| 레이어 | 0.2mm | 카운터보어 천장(브리지 Ø6.5)은 문제 없음 |
| 상/하판 | 5층 | 볼트 체결면 평탄도 |

브리징: 허브 포켓 천장(z=11, Ø10.6 스팬)과 카운터보어 천장은 짧은 브리지라 지지대 없이 출력됩니다.

## 공차 확인 (첫 출력 후)

설계 여유: 허브 보어 **반경 0.3mm**, 칼라-커프 **반경 0.4mm**.

1. 허브(Ø10.0)가 보어(Ø10.6)에 손힘으로 들어가는지 — 빡빡하면 보어를 10.8로 리모델 또는 슬라이서 XY 홀 보정 +0.1~0.2mm
2. 칼라(OD69.2)가 전완 커프(ID70.0)에 슬라이드 삽입되는지 — 헐거우면 테이프 한 겹으로 시험 후 69.4~69.6으로 조정
3. STEP 파일에서 치수 수정 → STL 재출력 (파라미터는 `scripts` 옆 `make_adapter_step.py` 참고)

## 하드웨어 (BOM)

| 수량 | 품목 | 용도 |
|---|---|---|
| 6 | M3×10 소켓헤드 (SHCS) | 베이스판 → elbow_roll 플랜지 (스톡 핸드와 동일 체결) |
| 4 | M3×8 셀프태핑 | 전완 커프 → 칼라 (Ø2.6 파일럿에 직결) |

## 조립 순서

1. 어댑터 베이스판을 elbow_roll 허브에 끼우고 6×M3로 플랜지에 체결 (60° 단위로 클로킹 가능 — 기본 0°)
2. V1 전완 커프를 칼라에 밀어 넣어 플로어(Ø84 면)에 안착
3. 커프 벽을 통해 4개 파일럿 위치에 마킹 → 커프에 Ø3.2 관통 드릴 → M3 셀프탭 체결
   (커프 기존 홀과 겹치면 어댑터를 회전시켜 회피 — 파일럿은 45°+90k)
4. 손목 3축을 전 구간 수동으로 돌려 간섭 확인 (시뮬 검증값: 최소 여유 0.47mm @ wrist_yaw 최대)
